# 动态分卷命名系统

## 📋 概述

动态分卷命名系统是一个智能的小说分卷管理方案，它允许系统在章节生成过程中自动创建和命名分卷，而不需要在项目初期就确定所有分卷的名称。

## 🎯 核心设计理念

### 传统分卷方式的问题

在传统的分卷系统中：
- 需要在项目开始时就确定所有分卷的名称
- 如果剧情发展与预期不符，分卷名称可能不准确
- 难以根据实际内容动态调整分卷结构

### 动态分卷命名的优势

- ✅ **延迟命名**: 分卷名称在内容生成后才确定，更贴合实际剧情
- ✅ **智能生成**: 使用AI基于已生成的章节内容生成分卷名称
- ✅ **灵活调整**: 可以根据剧情发展动态创建新分卷
- ✅ **无缝上传**: 与番茄小说等平台的上传逻辑完美配合

## 🔄 工作流程

### 1. 项目初始化

```
创建项目 → 自动创建第一卷"默认"
```

- 项目创建时，系统自动创建第一卷，名称为 `"默认"`
- 所有章节默认分配到这个"默认"卷

### 2. 章节生成阶段

```
生成第1章 → 第2章 → ... → 第30章
↓
所有章节都在"默认"卷中
```

- 章节持续生成，都分配到当前的"默认"卷
- 系统持续监控是否满足分卷条件

### 3. 触发分卷条件

**分卷条件:**
- **最小章节数**: 15章（不满足则不分卷）
- **最大章节数**: 30章（强制分卷）
- **评分阈值**: 平均评分 ≥ 60
- **重大事件**: 触发重大事件标记
- **高潮章节**: 单章评分 ≥ 80

### 4. 执行动态分卷

当满足分卷条件时，系统执行以下操作：

```
【步骤1】重命名当前"默认"卷
  "默认" → AI生成 → "第一卷：价值觉醒"
  
【步骤2】创建新的"默认"卷
  创建第二卷，名称为"默认"
  
【步骤3】后续章节分配
  第31章及以后 → 分配到新的"默认"卷（第二卷）
```

**关键点:**
- ✅ 已有章节（1-30章）保持在重命名后的第一卷
- ✅ 新章节（31章起）自动分配到新的"默认"卷
- ✅ 不需要手动移动章节

### 5. 循环重复

```
第31-60章生成 → 触发分卷 → 重命名第二卷 → 创建第三卷"默认"
第61-90章生成 → 触发分卷 → 重命名第三卷 → 创建第四卷"默认"
...
```

## 🔧 技术实现

### 1. 自动分卷服务 (`volume_split_service.py`)

**核心方法: `_create_volume()`**

```python
async def _create_volume(self, ...):
    """
    创建新卷（动态分卷命名系统）
    
    流程:
    1. 重命名当前"默认"卷为AI生成的正式名称
    2. 创建新的"默认"卷作为下一卷
    3. 记录日志
    """
    # 1. 获取当前最后一卷（应该是"默认"卷）
    last_volume = await self._get_last_volume(project_id)
    
    # 2. 生成当前卷的正式名称（基于已有章节内容）
    volume_title = await self._generate_volume_title(...)
    
    # 3. 重命名当前卷
    last_volume.title = volume_title
    
    # 4. 创建新的"默认"卷
    new_volume = Volume(
        volume_number=last_volume.volume_number + 1,
        title="默认",
        ...
    )
```

### 2. 分卷命名格式

**统一格式: `"第X卷：副标题"`**

示例:
- `"第一卷：价值觉醒"`
- `"第二卷：崛起之路"`
- `"第三卷：巅峰对决"`

**AI生成提示词:**
```
请为小说的第{volume_number}卷生成一个富有诗意和吸引力的卷名。

**要求**:
1. 卷名格式: "第{中文数字}卷：<副标题>"
2. 副标题应简洁有力，2-6个字
3. 体现本卷的核心剧情或主题
4. 富有诗意和想象力
```

### 3. 番茄上传服务 (`fanqie_publisher_service.py`)

**分卷同步逻辑:**

```python
for i, volume in enumerate(volumes):
    # 跳过"默认"卷
    if volume.title == "默认":
        continue
    
    # 去掉"第X卷："前缀
    volume_name = volume.title.split("：", 1)[1]
    
    # 检查番茄上是否有对应分卷
    if i < len(existing_volumes):
        fanqie_volume_name = existing_volumes[i]['name']
        
        if fanqie_volume_name != volume_name:
            # 名称不匹配，更新
            await self.edit_volume_name(fanqie_volume_name, volume_name)
    else:
        # 分卷不存在，创建
        await self.create_volume(volume_name)
```

**章节上传逻辑:**

```python
for chapter in chapters:
    # 跳过"默认"卷的章节
    if chapter.volume.title == "默认":
        continue
    
    # 上传章节到对应分卷
    await self.publish_chapter(...)
```

   ```sql

   ORDER BY volume_number;
   ```

### 用户

1. **创建项目**: 系统自动创建第一卷"默认"
2. **生成章节**: 持续生成章节，系统自动监控分卷条件
3. **自动分卷**: 达到条件时，系统自动重命名并创建新卷
4. **上传番茄**: 上传时自动同步分卷名称，跳过"默认"卷

## ⚠️ 注意事项

### 1. "默认"卷的特殊性

- ✅ "默认"卷是**待命名的卷**，不是最终名称
- ✅ 上传番茄时会**跳过"默认"卷**的章节
- ✅ 只有正式命名的卷才会上传

### 2. 分卷条件

- 建议至少生成15章后再触发分卷
- 强制分卷在30章时触发
- 可以通过评分和重大事件提前触发

### 3. 番茄上传

- 第一次上传时，会修改番茄上的"默认"分卷名称
- 后续上传会创建新分卷
- "默认"卷的章节不会上传，需要等待分卷命名
