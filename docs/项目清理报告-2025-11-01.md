## 📝 建议

### 1. 添加 .gitignore 规则

建议在 `.gitignore` 中添加以下规则，避免将来再次提交临时文件：

```gitignore
# 调试文件
debug_*.html
debug_*.png
*.log

# 测试脚本（临时）
test_*.py
test_*.sh
fix_*.py

# 数据库备份
*.db.backup
*.db-journal

# 临时文档
backend/*.md
```

### 2. 测试文件管理

- 正式的单元测试应放在 `backend/tests/` 目录
- 临时测试脚本应在测试完成后及时删除
- 或者创建 `backend/temp/` 目录存放临时文件（并加入 .gitignore）

### 3. 文档管理

- 正式文档统一放在 `docs/` 目录
- 临时分析文档应在整理后删除或归档到 `docs/archives/`
