## 功能概述

### 🎯 核心功能

番茄小说自动上传功能允许用户将本地创作的小说内容**一键同步**到番茄小说平台，无需手动复制粘贴。

### ✨ 主要特性

- ✅ **自动登录**：通过 Cookie 保持登录状态
- ✅ **书籍匹配**：自动查找或创建对应书籍
- ✅ **分卷同步**：智能同步本地分卷到番茄平台
- ✅ **批量上传**：支持一次性上传多个章节
- ✅ **增量更新**：只上传新增或修改的章节
- ✅ **错误重试**：上传失败自动重试机制

## 前置准备

### 1. 获取番茄小说 Cookie

#### 方法一：浏览器开发者工具（推荐）

1. **打开番茄小说创作平台**
   ```
   https://fanqienovel.com/writer
   ```

2. **登录账号**
   - 使用手机号/邮箱登录
   - 或使用第三方账号（微信/QQ）登录

3. **打开开发者工具**
   - Chrome/Edge：按 `F12` 或 `Ctrl+Shift+I`
   - Safari：`Cmd+Option+I`

4. **切换到 Network 标签**
   - 刷新页面（`F5`）
   - 找到任意请求（如 `api/writer/...`）
   - 点击请求，查看 Headers
   - 复制 `Cookie` 字段的完整内容

5. **Cookie 示例**
   ```
   sessionid=xxx; csrftoken=yyy; uid=zzz; ...
   ```

#### 方法二：使用浏览器插件

1. 安装 Cookie 导出插件（如 EditThisCookie）
2. 访问番茄小说创作平台并登录
3. 点击插件图标，导出 Cookie
4. 复制完整 Cookie 字符串

### 2. 在系统中保存 Cookie

1. **进入小说项目详情页**
   - 点击项目卡片进入详情

2. **切换到"番茄小说"标签页**
   - 在顶部导航栏找到"番茄小说"

3. **点击"立即登录"按钮**
   - 粘贴刚才复制的 Cookie
   - 点击"保存"

4. **验证登录状态**
   - 系统会自动验证 Cookie 是否有效
   - 显示"✅ 已登录"表示成功

### 🔄 详细步骤

#### Step 1: 验证登录状态

```python
# 后端代码：backend/app/services/fanqie_publisher_service.py

async def verify_login(self, cookie: str) -> bool:
    """验证 Cookie 是否有效"""
    headers = {"Cookie": cookie}
    response = await self.client.get(
        "https://fanqienovel.com/api/writer/user/info",
        headers=headers
    )
    return response.status_code == 200
```

**验证内容：**
- Cookie 格式是否正确
- Cookie 是否过期
- 用户权限是否足够

#### Step 2: 查找或创建书籍

```python
async def find_or_create_book(
    self, 
    cookie: str, 
    book_title: str
) -> Optional[str]:
    """
    查找书籍，如果不存在则创建
    
    返回：book_id (番茄平台的书籍ID)
    """
    # 1. 先查找是否已存在
    books = await self.list_books(cookie)
    for book in books:
        if book["title"] == book_title:
            return book["id"]
    
    # 2. 不存在则创建新书
    return await self.create_book(cookie, book_title)
```

**查找逻辑：**
- 通过书名精确匹配
- 如果找到多本同名书，选择最新的
- 如果找不到，自动创建新书

#### Step 3: 同步分卷信息

```python
async def sync_volumes(
    self,
    cookie: str,
    book_id: str,
    local_volumes: List[Volume]
) -> Dict[int, str]:
    """
    同步本地分卷到番茄平台
    
    返回：{本地分卷号: 番茄分卷ID} 的映射
    """
    volume_mapping = {}
    
    for volume in local_volumes:
        # 处理分卷名称（去除重复前缀）
        volume_name = self._clean_volume_name(volume.title)
        
        # 查找或创建分卷
        fanqie_volume_id = await self._find_or_create_volume(
            cookie, book_id, volume_name
        )
        
        volume_mapping[volume.volume_number] = fanqie_volume_id
    
    return volume_mapping
```

**分卷名称处理：**
```python
def _clean_volume_name(self, name: str) -> str:
    """
    清理分卷名称，避免重复前缀
    
    示例：
    输入：第一卷：初入修仙界
    输出：初入修仙界
    """
    if '：' in name or ':' in name:
        parts = name.replace(':', '：').split('：', 1)
        if parts[0].startswith('第') and parts[0].endswith('卷'):
            return parts[1]  # 返回冒号后的部分
    return name
```

#### Step 4: 批量上传章节

```python
async def upload_chapters(
    self,
    cookie: str,
    book_id: str,
    chapters: List[Chapter],
    volume_mapping: Dict[int, str]
) -> UploadResult:
    """
    批量上传章节
    
    返回：上传结果统计
    """
    success_count = 0
    failed_count = 0
    skipped_count = 0
    
    for chapter in chapters:
        # 1. 检查章节是否已上传
        if await self._is_chapter_uploaded(cookie, book_id, chapter.chapter_number):
            skipped_count += 1
            continue
        
        # 2. 获取章节所属分卷
        volume_id = volume_mapping.get(chapter.volume_id)
        if not volume_id:
            logger.warning(f"章节 {chapter.chapter_number} 没有对应的分卷")
            failed_count += 1
            continue
        
        # 3. 上传章节
        try:
            await self._upload_single_chapter(
                cookie=cookie,
                book_id=book_id,
                volume_id=volume_id,
                chapter_number=chapter.chapter_number,
                chapter_title=chapter.title,
                chapter_content=chapter.content
            )
            success_count += 1
        except Exception as e:
            logger.error(f"上传章节 {chapter.chapter_number} 失败: {e}")
            failed_count += 1
    
    return UploadResult(
        success=success_count,
        failed=failed_count,
        skipped=skipped_count
    )
```

**上传策略：**
- **增量上传**：只上传新章节，已存在的跳过
- **错误处理**：单个章节失败不影响其他章节
- **重试机制**：失败自动重试 3 次
- **限流保护**：每次上传间隔 1 秒，避免触发反爬

#### Step 5: 返回上传结果

```typescript
// 前端代码：frontend/src/components/FanqieUpload.vue

interface UploadResult {
  success: number;    // 成功上传数量
  failed: number;     // 失败数量
  skipped: number;    // 跳过数量（已存在）
  total: number;      // 总数
  message: string;    // 详细信息
}

const handleUploadResult = (result: UploadResult) => {
  if (result.failed === 0) {
    // 全部成功
    showSuccess(`✅ 上传完成！成功 ${result.success} 章，跳过 ${result.skipped} 章`);
  } else {
    // 部分失败
    showWarning(
      `⚠️ 上传完成，但有 ${result.failed} 章失败。\n` +
      `成功：${result.success} 章\n` +
      `跳过：${result.skipped} 章\n` +
      `失败：${result.failed} 章`
    );
  }
};
```

### 🔑 核心代码

#### 后端服务

**文件位置：** `backend/app/services/fanqie_publisher_service.py`

```python
class FanqiePublisherService:
    """番茄小说发布服务"""
    
    def __init__(self):
        self.base_url = "https://fanqienovel.com/api/writer"
        self.client = httpx.AsyncClient(timeout=30.0)
    
    async def upload_novel_to_fanqie(
        self,
        cookie: str,
        project: NovelProject
    ) -> Dict[str, Any]:
        """
        一键上传小说到番茄平台
        
        Args:
            cookie: 番茄小说 Cookie
            project: 本地小说项目
        
        Returns:
            上传结果统计
        """
        # 1. 验证登录
        if not await self.verify_login(cookie):
            raise ValueError("Cookie 无效或已过期")
        
        # 2. 查找/创建书籍
        book_id = await self.find_or_create_book(
            cookie, project.title
        )
        
        # 3. 同步分卷
        volume_mapping = await self.sync_volumes(
            cookie, book_id, project.volumes
        )
        
        # 4. 上传章节
        result = await self.upload_chapters(
            cookie, book_id, project.chapters, volume_mapping
        )
        
        return result
```

### 🔐 安全机制

1. **Cookie 加密存储**
   - 使用 AES-256 加密
   - 存储在数据库中
   - 仅用户本人可访问

2. **请求限流**
   - 每秒最多 1 个请求
   - 避免触发番茄平台反爬

3. **错误重试**
   - 网络错误自动重试 3 次
   - 指数退避策略（1s, 2s, 4s）

4. **日志记录**
   - 记录所有上传操作
   - 便于问题排查

## 常见问题

### ❓ Q1: Cookie 多久会过期？

**A:** 番茄小说的 Cookie 通常 **7-30 天**过期，具体取决于平台策略。

**解决方案：**
- 定期更新 Cookie（建议每周）
- 系统会在 Cookie 失效时提示重新登录

### ❓ Q2: 上传失败怎么办？

**A:** 常见失败原因：

1. **Cookie 过期**
   - 重新获取并保存 Cookie

2. **章节内容违规**
   - 检查章节内容是否符合平台规范
   - 避免敏感词汇

3. **网络问题**
   - 检查网络连接
   - 系统会自动重试

4. **分卷不存在**
   - 确保本地分卷信息完整
   - 系统会自动创建缺失的分卷

### ❓ Q3: 可以修改已上传的章节吗？

**A:** 可以，但需要注意：

- 系统默认**不会覆盖**已上传的章节
- 如需更新，请先在番茄平台删除旧章节
- 然后重新上传

### ❓ Q4: 上传速度慢怎么办？

**A:** 上传速度受以下因素影响：

1. **限流保护**：每秒 1 章，避免触发反爬
2. **网络延迟**：取决于你的网络环境
3. **章节数量**：章节越多，总时间越长

**优化建议：**
- 分批上传（每次 10-20 章）
- 在网络状况良好时上传

### ❓ Q5: 支持哪些内容格式？

**A:** 支持的格式：

- ✅ 纯文本
- ✅ 段落分隔（`\n\n`）
- ✅ 对话格式（`"xxx"` 或 `「xxx」`）
- ❌ 不支持 Markdown
- ❌ 不支持 HTML 标签
